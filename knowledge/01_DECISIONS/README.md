# 01_DECISIONS

Decisiones técnicas tomadas durante el desarrollo que **no** están en `docs/` o que necesitan más detalle de contexto (alternativas, motivo, consecuencias).

- Plantilla: [[TEMPLATE_DECISION]]
- Una decisión **no puede contradecir** la documentación oficial. Si la implicaría, no es una nota: es una propuesta de revisión de `docs/` que debe aprobarse explícitamente.
- Si la decisión ya está en `docs/`, no la copies: enlázala.
- Estados: `PROPOSED` → `ACCEPTED` (solo con aprobación explícita registrada en la nota) → `OBSOLETE`. Una decisión no se verifica: se aprueba.
- Nombre: `AAAA-MM-DD_slug.md`. Añádela a [[INDEX]].
