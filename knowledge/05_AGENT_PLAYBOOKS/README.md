# 05_AGENT_PLAYBOOKS

Procedimientos de trabajo repetibles para **Claude Code durante el desarrollo** (p. ej. «cómo preparar una fase», «cómo diagnosticar un fallo de test»).

- **No** son instrucciones para los agentes de la agencia (Market Intelligence Agent, etc.); ese comportamiento lo define `docs/AGENT_SPEC.md`.
- Un playbook no puede contradecir `CLAUDE.md` ni `docs/MASTER_DEVELOPMENT_PROMPT.md`; los complementa con pasos operativos.
- Cada playbook indica cuándo se aplica, los pasos, y cómo se comprueba que se hizo bien.
- Estados: `PROPOSED` → `ACCEPTED` (aprobado para usarse) → `OBSOLETE`.
- Vacío por ahora; se creará cuando exista un procedimiento que se repita.
